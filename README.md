## 🚀 Current Projects

- **Yorùbá–Igbo–Hausa Speech-to-Speech Translation** 🔒 *(private repository until the MSc is examined; happy to walk through it on request)* – *MSc research: a cascaded speech recognition → translation → speech synthesis system for all six directions between Yorùbá, Igbo and Hausa. Every stage is measured on real speech, each end-to-end failure is traced to the stage that caused it, and the weakest stages (the Igbo voice, the recogniser, the translators) were fine-tuned on NaijaS2ST. Output quality rose by a third over the pretrained baseline; now heading for a free mobile app.*
